Core capabilities

Everything a modern server owner expects on day one.

Geyser ready

Geyser and Floodgate are bundled with working defaults, Bedrock UDP 19132, and web-visible configuration.

Chat report protection

NoChatReports is handled by HunterCore itself, with command, GUI, and WebPanel controls.

WebPanel operations

Dashboard, assets, permissions, titles, settings, players, chat, maps, plugins, and health views in one web surface.

HunterAssets

Publish resource packs, define custom model data items, validate packs, and serve downloads from the panel.

AI and fake players

AI chat, NPC responses, real fake player actions, safety windows, and workload throttling are built in.

Custom login UI

HunterAuth asks players to install the UI pack, opens a custom login GUI, and falls back cleanly if declined.

Map and server tools

BlueMap, Chunky, LuckPerms, WorldEdit, WorldGuard, Vault, ProtocolLib, ViaVersion, and more are prepared.

Command coverage

Traditional commands remain available while `/hc` exposes a graphical control path for everyday workflows.

Graphical control

The `/hc` menu is the front door. Admin commands stay commands.

Players can open `/hc` directly, while admins keep traditional `/hc admin ...` commands. The GUI now routes into real workbenches for AI, optimization, modules, assets, titles, NoChatReports, web settings, fake players, NPCs, story mode, and command categories.
